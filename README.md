# Yooka-Replaylee PopTracker

A PopTracker pack for Yooka-Replaylee Archipelago. This project is still being improved; please report errors via Discord.

## Install v2.72.13

1. Use **PopTracker 0.35.4 or later**.
2. Open the [latest release](https://github.com/Xannon-rgb/Yooka-Replaylee-PopTracker/releases/latest).
3. Download **Yooka-Replaylee_PopTracker_v2.72.13.zip** from the release Assets.
4. Drag the ZIP into PopTracker, or place it in the PopTracker packs folder **without extracting it**.
5. Select the HD, Full HD, 1440p, 4K, or Horizontal/Widescreen layout.
6. Connect PopTracker to your Archipelago server with the correct slot and room password (if applicable).

Use the named tracker ZIP, not GitHub's autogenerated **Source code** archives.

## Changes in v2.72.13 — World logic and collectible artwork

- All location checks in Glitterglaze Glacier, Moodymaze Marsh, Capital Cashino, and Galleon Galaxy now require their corresponding Progressive Pagie Doors (15, 35, 55, and 75 respectively), in addition to existing move requirements.
- IcyMetric Tower quill sections have individual access rules and collected-state tracking.
- Quill checks use world-specific colored quill artwork; collected groups turn gray. Galleon Galaxy groups display remaining individual quill counts.
- Golden Pagie checks use the complete Golden Pagie artwork and turn gray when collected.
- Pagie Piece checks use the new transparent artwork with the eyes and smile intact, and turn gray when collected.
- Automatic world map switching from v2.71.1 remains supported.

## Automatic world map switching (introduced in v2.71.1)

The tracker now **automatically switches to the matching map** when you enter a world and switches back to **Hivory Towers** when you return to the hub. Supported maps include Tribalstack Tropics, Glitterglaze Glacier, Moodymaze Marsh, Capital Cashino, Galleon Galaxy, and Hivory Towers.

**Required game mod update:** Automatic map switching needs the updated **MelonLoader Archipelago mod** from the **main Yooka-Replaylee Archipelago page**. Update the game-side mod (including its accompanying Archipelago.MultiClient.Net.dll, when provided) before using this feature. An older mod may still connect but will not publish the active-world data needed for map switching. Back up existing mod DLLs and follow the mod developer's installation instructions.

## Automatic PopTracker pack updates

The pack uses [versions.json](https://raw.githubusercontent.com/Xannon-rgb/Yooka-Replaylee-PopTracker/main/versions.json) to discover published updates. GitHub Actions indexes published release ZIP assets and records their verified SHA-256 checksums. PopTracker handles update checking and installation. Older packs without the feed URL need a one-time manual installation.

**Maintainers:** Publish a release tagged `v2.72.13` and attach exactly one asset named `Yooka-Replaylee_PopTracker_v2.72.13.zip`. The update-feed workflow then indexes its internal package version and checksum. Do not manually point the feed at a nonexistent release asset.
